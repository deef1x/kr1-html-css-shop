# ShopProject — контрольная работа №1

## Описание проекта

Многостраничный учебный HTML/CSS-сайт интернет-магазина. Проект демонстрирует семантическую HTML-разметку, единую навигацию, карточки товаров, форму заявки, CSS Grid, Flexbox и БЭМ-именование классов.

## Страницы проекта

- `index.html` — главная страница, преимущества и популярные товары;
- `catalog.html` — каталог товаров и статические фильтры;
- `product.html` — карточка товара и таблица характеристик;
- `order.html` — форма оформления заявки;
- `contacts.html` — контактная информация.

## Используемые технологии

- HTML5;
- CSS3;
- Flexbox;
- CSS Grid;
- CSS-переменные;
- БЭМ;
- JavaScript для открытия/закрытия модального окна и клиентской проверки формы;
- Git и GitHub Pages.

## Реализованные элементы

- единая навигация на всех страницах;
- якорные ссылки на главной странице;
- хлебные крошки на внутренних страницах;
- карточки товаров и сетка каталога;
- блок фильтров каталога (статическая разметка);
- отдельная страница товара с таблицей характеристик;
- форма заявки и модальное окно;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- CSS-переменные;
- позиционирование `relative`, `absolute`, `sticky`, `fixed` и `z-index`;
- БЭМ-именование основных блоков и элементов.

## Проверка проекта

Откройте `index.html` в браузере или запустите проект через расширение Live Server в Visual Studio Code. Проверьте переходы между пятью страницами, ссылки-якоря, открытие модального окна, проверку обязательных полей и отображение таблицы товара.

Форма демонстрационная: данные не отправляются на сервер.
